# TEL_Robot_2026 程式逐段說明

依據 dev `2f974af`（2026-11-07）。行號是每個檔案自己的行號，程式改過之後行號會跟著變。
閱讀順序：main.cpp → Auto → Shooter（含 VisionFollowController、TurretGuard）→ ManualControl → Dribbler → Art → Chassis → TurretAngle → Vision。

單位慣例：
- 時間：ms（`millis()`）
- 脈寬：us
- 命令：−1～+1 的比例（飛輪是 0～1）
- tx / ty：相機畫面上的 px
- 距離：Vision 用 mm，Auto 用 m
- 角度：°

| 行 | 做什麼 |
|---|---|
| 98–99 | 輸出限制 ±1，I 項限制 ±0.12 |
| 102–114 | `reset()`：全部清零 |
| 121–124 | 沒看到目標或 tx 不合法 → 重設，輸出 0 |
| 125–134 | 第一次看到、換了洞、或超過 100 ms 沒更新 → 重新開始，這一圈輸出 0（避免一次累積太多） |
| 136–138 | dt（秒）；記錄這一幀 |

| 142–143 | 進入 ±5 px 範圍後，I 項停止增加 |
| 144 | **PID**：`PidfController.calculate(目標 0, 量測 tx, dt)` + D |

| 151–171 | **停滯推力**：在 ±5 px 外，而且 |txRate| < 30 px/s → 開始計時；靜止 200 ms 後推 80 ms，命令至少 0.17、朝目標方向；推完要再靜止 200 ms 才推下一次 |
| 173–182 | **ready**：|tx| ≤ 5 px 持續 250 ms |
| 186–193 | 讀值（P、I、D、txRate、是否在推） |

`PidfController.calculate()`（`src/Control/PidfController.cpp` 51–132 行）：
- **誤差**：`誤差 = 目標 − 量測`，`P = kP × 誤差`
- **D**：用量測值的變化率算，`D = −kD × (量測 − 上次量測) / dt`（不對誤差微分，換目標時不會突然跳）
- **I**：只在 |誤差| ≤ kIZone 時累積，`I = kI × ∫誤差 dt`，限制在 I 項上下限內
- **防飽和**：加上這次的 I 之後輸出會超出上下限，就不更新 I；但如果新的 I 能把輸出拉回範圍內，仍然更新
- **輸出**：`P + I + D + F`，限制在上下限內

例子：tx = 40 px → P = −0.01 × 40 = −0.4 → 轉台送 1500 − 0.4 × 500 = 1300 us。
