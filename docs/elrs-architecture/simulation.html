4　LED：看到的是哪個判斷？
刻意重現現有程式的限制：曾收過一次 Battery 後，其他類型 frame 也會刷新回傳時間。因此恆亮不保證假電池持續正確回來。將「最近任意 frame」設1499與1500比較邊界。


5　純 C 測試與真實硬體如何分工
Host test：build_rc → parser_push ×26 → unpack → tick_to_us → CHECK，測的是陣列內資料。
實體下行：send_rc → USART1_DR → PA9 → ES900TX → RF → ES900RX → PA3 → USART2_IRQHandler。
實體回傳：send_battery → USART2_DR → PA2 → ES900RX → RF → ES900TX → PA9 → USART1_IRQHandler。
目前不是「收RC才回ACK」，兩個發送器獨立每10ms／1000ms排程。沒有封包序號或往返延遲量測。
