# A. 判斷邏輯

## A1. 誰能控制機器人（ManualControl）

```
每一圈，先檢查 watchdog，再讀新輸入：

有線控制中 且 250 ms 沒收到任何指令或心跳 K     → 停用（COMMAND_TIMEOUT）
無線控制中 且 遙控斷線（200 ms 沒有有效的 RC 行）→ 停用（RC_LINK_LOST）
無線控制中 且 250 ms 沒有可解碼的資料           → 停用（COMMAND_TIMEOUT）

收到啟用要求（有線 E，或無線 CH6 由低變高）：
    腳位表未確認                   → 拒絕
    另一個來源正在控制              → 拒絕
    無線：CH4 不是全手動，或飛輪不為 0 → 拒絕
    否則 → 清空所有命令、模式設成全手動、選洞清空、
           送球塔 / 底盤 / 發射頭全部啟用、控制者 = 這個來源

停用：
    有線 X → 任何來源都停
    無線 CH6 由高變低 → 只停無線
```

- **同一時間只有一個控制者。** 另一個來源送來的動作、F、選洞，都會回報「不是控制者」。
- **無線按鍵看邊緣，不看電位。** 啟用、發射、自動路徑、RB 都要「先放開再按」才算一次；斷線後一律要先看到放開，所以訊號恢復時不會自己啟用或自己發射。

## A2. 每種模式下各部位歸誰控制

| 部位 | 全手動 | 測試 | 半自動 | 全自動 |
|---|---|---|---|---|
| 底盤 | 操作手 | 操作手 | 操作手 | 操作手 |
| 轉台 | 操作手 ←→ | Auto（跟鏡頭） | Auto | Auto |
| 仰角 | 操作手 ↑↓ / ANGT | 操作手 | Auto（射擊表）＋↑↓ 微調 | 同半自動 |
| 飛輪 | 操作手滑桿 | 操作手滑桿 | Auto（射擊表）＋LT/RT 微調 | 同半自動 |
| 發射 F | 直接觸發塔 | 直接觸發塔 | 交給 Auto，條件全部滿足才射 | Auto 自己射，F 不影響 |

- 停用時一律算全手動，每次 Enable 都從全手動開始。
- 切換模式時，轉台和飛輪的命令會歸零，F 請求也會清掉。

## A3. 轉台命令由誰決定（Auto `aimTurret` → Shooter `updateRotate`）

依序檢查，第一個成立的就採用：

1. TurretGuard 正在回 0° → 由保護接手
2. 自動 / 測試模式下按住 ←→（或放開後還在 0.3 秒等待中）→ 手動轉；等待期間輸出 0
3. 按過 RB → 停在 0°
4. 相機不正常（Orin 沒連線，或沒有回報 READY）→ 停住
5. 選的洞不在畫面上、還沒找到過、而且找不到 3 秒 → 以 0.3 往那個方向找洞
6. 其餘 → 視覺 PID（輸入是 `tx + 微調 offset`）

最後一律經過 TurretGuard（A6）才真正輸出。

## A4. Auto 每一圈的判斷（半自動、全自動）

```
1. 相機不正常 → 轉台停住、飛輪 0、狀態回 IDLE、按 F 回報「未就緒」，這圈結束。
2. 距離濾波：
     換洞（選擇改變，或 Orin 換了目標） → 濾波器重來
     這一幀有效、有深度、是新的一幀     → 加一個樣本
3. hasTarget = 這一幀有效 且 有深度 且 濾波器有穩定距離 且 這個洞有射擊表
     成立 → 存下射擊值（轉速、仰角、洞號、時間）
4. holding = 這一幀沒有目標，但 500 ms 內同一個選擇有過射擊值 → 沿用
     兩者都不成立 → 清掉射擊值和濾波器
5. 有目標或沿用中：
     飛輪 = 表 + 微調%（0～1）
     仰角往「表 + 微調」移動，每秒最多 400 us
   都沒有：飛輪 0.2 預轉，仰角保持不動
6. ready = 下面全部成立：
     轉台 ready（|tx+offset| ≤ 5 px 持續 250 ms，而且是真的看到）
     飛輪 ready（命令不變滿 1.5 s）
     有射擊值（這一幀看到，而且有表或沿用中的同一個洞）
     仰角到位（離目標 ≤ 10 us）
     洞沒有被排除（全自動不射 1、4、7）
     換洞後已過 500 ms
     塔有球（只在 READY_REQUIRED 開啟時才檢查）
7. 狀態機（A5）
```

## A5. 射擊狀態機（Auto）

```
IDLE ──(進入自動模式)──► SPINNING_UP
SPINNING_UP ──(ready)──► READY            （同一圈就可以射）
READY ──(ready 不成立)──► SPINNING_UP
READY ──(全自動且還沒射完，或半自動按了 F)──► 送出發射：
        塔接受   → COOLDOWN，全自動記一顆
        塔拒絕   → 按 F 時回報 FEED_BUSY；全自動下一圈再試
COOLDOWN ──(300 ms)──► SPINNING_UP
半自動按 F 但沒射出去 → 回報 FIRE_NOT_READY，不會排隊，要再按一次
```

另外，塔本身有 1000 ms 的冷卻時間（A8），所以兩發之間至少隔 1 秒。

## A6. 轉台保護 TurretGuard（每個轉台命令都要經過）

```
曾經發生方向錯誤          → 0（要重開機才解除）
沒有絕對角度              → 0（UNKNOWN：開機時不在歸位點 ±25° 內，或 AS5600 斷過）
AS5600 讀值不正常         → 0（SENSOR）
正在回 0°                → 用 P 控制開回 0°（B9）
算出「預估停下的角度」→ 越接近極限，命令越小（B8）
方向檢查：命令 ≥ 0.2 時，先等 150 ms 才開始觀察，之後如果往反方向走了 ≥ 2° → 鎖住
```

- **可以鎖定射擊的狀態**只有三種：正常、到右極限、到左極限。
- **自動回 0°** 會發生在兩種情況：開機後的第一次 Enable，以及按下 RB。

## A7. Orin 的一幀資料要不要用（Vision）

```
欄位數必須是 6、8 或 9，每一欄都要是合法數字，而且在範圍內 → 否則整幀作廢
valid = Orin 說看到（=1） 且 （沒有選洞，或這一幀就是選的那個洞）
預測位置（=2）：必須是選的那個洞，而且從第一次預測起不超過 3 秒
               → 只拿來轉轉台，距離一律設 0，所以永遠不會依它射擊
300 ms 沒收到資料 → 作廢（判定沒連線）
換洞 → 手上那一幀立即作廢（它是舊洞的資料）
```

## A8. 送球塔（Dribbler）

```
停用 → D15 = HIGH，D22 = LOW
啟用 → D15 = LOW
發射（requestFeed）：
    停用中 或 脈衝進行中 或 距上次發射不到 1000 ms → 拒絕
    READY_REQUIRED 開啟 且 沒有球                   → 拒絕
    其他 → D22 拉 HIGH 100 ms，已發射數 +1，清掉「有球」
D14：
    HIGH 持續 ≥ 20 ms 算一次脈衝 → 設成「有球」
    原本沒球才把「已裝」+1（Nano 每次 Enable 會重送同一顆球的脈衝）
```

## A9. 全自動的打洞順序（Auto 排序）

```
每次切換模式或重新選洞 → 排序重來
看到亮燈的加分洞、還沒打過、而且有射擊表 → 先打它 3 顆；熄燈超過 1 秒後才可以再打
操作手有選洞 → 從那個洞開始；沒選洞 → 從第一顆射到的洞開始
Orin 自己挑到被排除的洞 → 改從同一欄最近、沒被排除的洞開始（例：4 → 5）
每個洞 3 顆 → 換下一個；遇到沒有射擊表或被排除的洞就跳過；全部打完 → 停
例：從 5 開始 → 5、8、9、6、3、2、Q、W、E
```

## A10. 創意設計（Art）

```
已發射數增加（任何模式下，D22 真的送出一次）：
    啟用中 → 連桿 D47 轉 2 s
    D41 動感光波 HIGH 1 s（如果還在 HIGH，先拉 LOW 50 ms 再拉 HIGH）
啟用中瞄的洞（Auto／操作手的洞，沒有就用相機鎖定的洞）換成另一個洞 → 等動感光波開始滿 3 s、D42 沒在播 → 50 ms 後 D42 哇哈哈 HIGH 1 s（鎖定、微調不算）
停用 → 連桿立刻停；D40 準備好了：馬上播一次，之後每 10 s（開始到開始）一次；前 3 次 HIGH 1 s；之後每次結巴 =
    4 × (HIGH 0.15 s → LOW 0.05 s) + HIGH 1 s（準準準準準備好了），Enable 立刻拉 LOW、次數歸零
```

# B. 算法與公式

## B1. 命令換成 PWM 脈寬（Shooter `commandToPulseUs`，底盤也一樣）
```
c' = INVERTED ? −c : c                     （c 先限制在 −1～1）
c' ≥ 0：pulse = 1500 + c' × (max − 1500)
c' < 0：pulse = 1500 + |c'| × (min − 1500)
```
- 轉台、底盤、連桿：1000–2000 us。例：0.5 → 1750 us。
- 飛輪：命令 ≤ 0 時送 1490 us（停止脈寬 = 1500 + STOP_PULSE_OFFSET_US −10）。

## B2. 底盤
```
去死區： |x| < 0.04 → 0；否則 sign(x) × (|x| − 0.04) / 0.96
混合（Chassis::setOpenLoop）： L = f + t，R = f − t
       若 max(|L|,|R|) > 1，兩邊都除以 max(|L|,|R|)
無線搖桿換成坦克式（ManualControl）： L = f − t，R = f + t
低通（只管加速，2026-11-08）：
     目標和 y 反向 → y 先歸 0
     |目標| ≤ |y|（減速、放開） → y = 目標，直接到
     其他（加速） → α = dt / (dt + 80 ms)，y += (目標 − y) × α
```
- 加速：每圈 10 ms 時 α = 0.111，大約 0.2 秒到達 90%。
- 例：全速前進時放開搖桿 → 下一圈就送 1500 us；從前進直接推到後退 → 先停，再用 80 ms 慢慢加速往後。
- 例：L = 0.854 → 穩定後送 1500 + 0.854 × 500 = 1927 us。

## B3. 轉台視覺 PID（VisionFollowController + PidfController）
```
e = 0 − (tx + offset)
P = kP × e                              kP = 0.01
I = kI × ∫e dt                          kI = 0.01，只在 |e| ≤ 20 px 時累積，上限 ±0.12
                                        在 ±5 px 內 I 停止累積；I 會造成超出輸出上下限時不累加（防飽和）
txRate ← 0.5 × txRate + 0.5 × Δtx/Δt     （每一張新幀更新一次）
D = −0.0008 × txRate                     （相當於預測 80 ms 後的位置）
u = clamp(P + I + D, −1, 1)
停滯推力：|e| > 5 px 且 |txRate| < 30 px/s 持續 200 ms
          → 80 ms 內，朝目標方向的命令至少 0.17
ready：|e| ≤ 5 px 持續 250 ms
```
- 例：tx = 40 px → P = −0.4 → 1300 us。
- 例：tx 停在 8 px 不動 → 等 200 ms 後，推一下 0.17、持續 80 ms。

## B4. 找洞
```
選的洞不在畫面上、還沒找到、而且不到 3 s → u = 方向 × 0.3
方向由 OperatorTarget::searchDirection 決定（依選的洞跟畫面上看得到的洞、最後看到的欄比較）
```

## B5. 距離濾波（ShotDistanceFilter）
```
m = 最近 5 幀的中位數（m）
|m − 目前採用值| ≤ 0.05 m → 不變（視為雜訊）
|m − 目前採用值| > 0.05 m 且持續 300 ms → 採用值 = m
```
- 例：站著不動時，距離在 3.48～3.52 m 之間跳 → 採用值不變，射擊表查到的值也就不變。

## B6. 射擊表內插（ShotTableLookup）
```
找出 d1 ≤ d ≤ d2 的兩點
t = (d − d1) / (d2 − d1)
轉速   = f1 + (f2 − f1) × t       （限制在 0–1）
仰角us = e1 + (e2 − e1) × t + trim[洞]
d 比第一點近 → 用第一點；比最後一點遠 → 用最後一點（不往外推）
```
- 例：洞 4，3.30 m 是 32.0%、3.65 m 是 33.0%，量到 3.50 m → t = 0.571 → 32.57%。

## B7. 仰角
```
Auto：目標 = clamp(表 + 微調, 500, 2461)
      每圈最多移動 = 400 us/s × min(dt, 100 ms)
      到位 = |目標 − 目前| ≤ 10 us
手動：目標 += 指令 × 1000 us/s × dt（限制在 500–2461；dt > 100 ms 時不動）
度數（只給 Dashboard 看）：deg = (us − 500) × 270 / 2000
```
- 例：從 2461 移到 1200 → 1261 / 400 ≈ 3.15 s。
- 例：500 us 顯示為 0°，1500 us 顯示為 135°。

## B8. 轉台極限減速（TurretGuard）
```
速度：v += (Δθ/dt − v) × min(1, dt / 0.05 s)
停下角度 = θ + v × 0.15 s      （只在命令方向跟目前轉動方向相同時才加上這段）
剩餘角度 = 往右轉時 38.5° − 停下角度；往左轉時 停下角度 − (−166°)
剩餘 ≤ 0       → u = 0
剩餘 < 10°     → u × max(剩餘 / 10, 0.2 / |u|)
```
- 例：在 +33.5°、u = 0.8 往右 → 剩 5° → 0.4。

## B9. 回 0°（TurretGuard）
```
u = clamp(0.05 × (0 − θ), −1, 1)
|θ| > 1° 時，|u| 至少 0.2
|θ| ≤ 1° 持續 200 ms → 完成；超過 5 s 也結束
```
- 例：θ = −30° → 0.05 × 30 = 1.5，限制在 1.0。

## B10. AS5600 轉台角度（TurretAngle）
```
每度 counts = 4096 × (180 / 36.5) / 360 = 56.11
每 10 ms：Δ = 折半(raw − 上次 raw)   （折到 −2048～+2047，跨過 0/4095 時才算得對）
         counts += Δ
角度 = −counts / 56.11                （INVERTED）
開機：counts = 折半(raw − 歸位 raw)；|角度| ≤ 25° 才算有絕對角度
100 ms 沒讀到 → 失去絕對角度（不知道中間轉了幾圈）
```
- 例：歸位 raw 3918，開機讀到 522 → Δ = +700 → −12.5°。
- 磁鐵轉一圈 = 4096 counts = 轉台轉 73°。

## B11. 飛輪
```
斜坡：每圈最多變化 0.5/s × min(dt, 100 ms)
脈寬：命令 > 0 → 1500 + 命令 × 500；命令 = 0 → 1490
ready：命令維持在 ±0.02 內滿 1.5 s     （用時間推算，沒有轉速感測）
```
- 例：0 → 0.33 要 0.66 s，再等 1.5 s 才算 ready，總共約 2.2 s。

## B12. 微調
```
水平：放開 ←→ 0.3 s 後，offset = clamp(−tx, ±300 px)；之後 PID 的輸入 = tx + offset
仰角：按住每秒 ±200 us（放開就停在那裡），總共最多 ±200 us
  測試模式（仰角是手動的）：放開 ↑↓ 時 offset = clamp(目前仰角 − 射擊表在這個距離的仰角, ±200 us)
  例：表 1600 us、手動調到 1650 us 放開 → +50 us，之後自動模式都用 表 + 50
記住（2026-11-08）：水平、仰角兩個 offset 所有洞共用，換洞、換模式、Enable、斷電都保留（EEPROM 400–413）；只有 C 清成 0
轉速：LT/RT ±20%（FLYO），直接加在射擊表的轉速上（換洞、換模式歸零，不記住）
```

## B13. 洞號換算（OperatorTarget）
```
Dashboard 鍵 k（1–9）→ Orin id = 4 + (2 − (k−1) % 3) × 3 + (k−1) / 3
加分洞 Q W E（Dashboard 10–12）→ id 1–3
```
- 例：鍵 1 → 10，鍵 5 → 8，鍵 9 → 6。

## B14. 送球塔時序
```
D22 脈衝 100 ms，接著冷卻：從脈衝開始算 1000 ms 內拒絕下一發
D14 消抖：HIGH 持續 20 ms 才算一次
已裝數 + 1 只在「原本沒球」時
```

## B15. 無線回傳打包（RcControlMap）
```
每 100 ms 一格，6 格一輪：狀態、瞄準、狀態、視覺、seen、球數（狀態約每 300 ms 一次）
用 code 的最高 2～3 bit 分辨種類：00 狀態、010 視覺、011 球數、10 瞄準、11 seen
tx、ty：以 0.5 px 為單位存成 12 bit 二補數 → v = round(tx × 2)，範圍 ±1023.5 px
距離：cm，14 bit
AS5600 角度：度 × 10，12 bit 二補數（±204.7°）
深度環：0 表示沒有資料，否則 = 百分比 / 2 + 1
球數：已裝、已發射 各 mod 4096
```

## B16. 創意設計
```
連桿脈寬 = 1500 − 0.4 × 500 = 1300（INVERTED，COMMAND 0.4），持續 2 s
音效：平常 LOW，播放時 HIGH 1 s；如果還在 HIGH，先拉 LOW 50 ms
哇哈哈：每換一次洞播一次；動感光波開始後 3 s 內不播（模組一次只播一個，新的會切掉舊的）
準備好了：停用中每 10 s 一次（開始到開始）；前 3 次 HIGH 1 s；之後每次 4 × (0.15 + 0.05) s 結巴 + 1 s
```
